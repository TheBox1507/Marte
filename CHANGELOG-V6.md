# Mars Explorer V6

- Integración del logotipo Mars 2020 suministrado por el usuario en encabezado y favicon.
- Rediseño visual V6 con jerarquía de botones, paleta marciana de campo y controles más grandes.
- Resolución de configuración WMTS desde NASA Mars Trek GetCapabilities para capas MOLA Roughness y TES Dust, con fallback TES Dust Index.
- Estados de capas diferenciados para carga, disponibilidad y error.
- Leyenda visual de capas cartográficas.
