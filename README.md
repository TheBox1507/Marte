# JEZERO V38 — Directional Traverse UI

Actualización visual para mejorar la comprensión inmediata del recorrido EVA.

La interfaz ahora comunica tres cosas sin depender de interpretar una línea aislada:
1. dónde comienza/termina la misión;
2. cuál es el orden calculado de los puntos;
3. en qué sentido se recorre cada tramo.

La actualización es ligera y utiliza únicamente estilos vectoriales de OpenLayers, CSS y HTML existentes.
