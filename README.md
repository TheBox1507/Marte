# JEZERO V35

Sistema de planificación de travesías científicas EVA en Marte.

V35 amplía V34 con un **Mission Analytics Center** y un **Mission Report** mucho más visual y exhaustivo. El motor de planificación, las capas de Marte, la nomenclatura IAU/USGS y el análisis MDEM200M se conservan.

La aplicación no incorpora una librería externa de gráficos: las visualizaciones de la interfaz se construyen con SVG/HTML/CSS y el PDF usa gráficos vectoriales generados por `pdf-report.mjs`.

Consulta `ACTUALIZAR-GITHUB-V35.md` para instalar la actualización y `CHANGELOG-V35.md` para el detalle de cambios.
