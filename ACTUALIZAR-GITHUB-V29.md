# Actualización a JEZERO V29

Reemplaza en tu repositorio estos archivos:

- `index.html`
- `style.css`
- `script.js`
- `pdf-report.mjs`
- `modules/module-shell.js`

Puedes agregar también:

- `CHANGELOG-V29.md`
- `ACTUALIZAR-GITHUB-V29.md`

No es necesario reemplazar `server.mjs`, `mars-elevation.js`, `mars-data.json`, assets ni la base de datos para esta actualización.

## Después de subir
1. Recarga la página con Ctrl+F5.
2. Abre Ciencia y verifica que aparezcan los objetivos creados en Planificar.
3. Abre Configuración y define el nombre/ID de misión.
4. Calcula una misión.
5. Abre Resultados y genera el PDF.

Si el navegador conserva el módulo activo de V28, V29 migra automáticamente `Informes` a `Resultados`.
